# Backend Developer | Full-Stack Developer

Backend & Full-Stack Developer from Argentina. **Higher Technician in Software Development** (*Técnico Superior en Desarrollo de Software*) and **B.Sc. student in Data Science** (*Licenciatura en Ciencia de Datos*) at **Universidad de la Ciudad de Buenos Aires (UDECI)**.

Specialized in scalable backend APIs, resilient architectural patterns, relational data modeling, multi-provider LLM orchestration, and high-performance client-side data analytics.

## 🛠️ Core Focus & Capabilities

- **Backend & Data Modeling:** Scalable asynchronous REST APIs with FastAPI & Python 3.12; strict relational schemas, migrations, and constraint enforcement using PostgreSQL, SQLModel/SQLAlchemy, and Alembic.
- **Architectural Engineering:** Resilient domain architectures (Hexagonal, Event-Driven, Transactional Outbox), strict idempotency, and offline-first data replication strategies.
- **AI Tooling & LLM Orchestration:** Multi-provider integration (Vercel AI SDK, Gemini, OpenAI, Groq), streaming interactions, automated repository & CV audits, and deterministic structured outputs.
- **High-Performance Client Data Processing:** In-browser analytical query engines using DuckDB-Wasm and WebAssembly pipelines for zero-server-latency data exploration.
